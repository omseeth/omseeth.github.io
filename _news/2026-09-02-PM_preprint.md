Another preprint available! I like the basic idea behind it: instead of replacing data algorithms from process mining with foundation models, we use LLMs to 'translate' messy data into a format those algorithms can actually work with. Process mining and generative AI still aren't well connected, and this is one way to bridge them. Link to paper: [Automated Event Log Generation from Unstructured Text Using Finetuned LLMs](https://arxiv.org/abs/2609.01320)
